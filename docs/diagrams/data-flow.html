EasyLab — User Journey & Data Flow

From first upload to final CSV export
1

Create project & upload images

User · Browser
User opens app → workspace cookie auto-created → creates a named project → drops 10–50 lab images. Each image is uploaded directly to Supabase Storage via a signed URL minted by Next.js.
Browser Next.js mints URL Storage receives file
2

Pick reference image

User · Browser
User selects one image from the uploaded grid as the reference. This is the image they'll annotate. PATCH updates projects.reference_image_id.
Browser Next.js Postgres
3

Annotate fields on reference

User · Browser (react-konva)
User draws rectangles on the reference image and names each field (e.g. "Voltage", "Current"). Optionally sets expected format. Boxes are stored normalized 0..1 — never in display pixels.
react-konva canvas POST /api/projects/:id/fields template_fields rows
4

Enqueue extraction job

Next.js · Server
User clicks "Start Processing". Next.js checks workspace_quota (returns 429 if exceeded), then inserts a row into jobs with status=queued. UI redirects to the processing page and starts polling.
POST /api/projects/:id/jobs jobs row inserted workspace_quota++
5

Worker picks up job

FastAPI · Fly.io
FastAPI polls jobs with FOR UPDATE SKIP LOCKED, claims the queued job, sets status=running. Heartbeat every 5s.
asyncio worker jobs.status → running
6

AI pipeline runs

FastAPI + Gemini + PaddleOCR
Stage A: Gemini 2.5 Pro enriches the template (semantic descriptions). Stage B: detects regions in each non-reference image. Stage C: Gemini Flash + PaddleOCR read values from each crop. Each cell row is written with confidence + status.
Stage A · Pro Stage B · Pro Stage C · Flash + OCR cells, crops written
7

Review table

User · Browser
When job succeeds, UI loads cells as a table: rows = images, columns = fields. Each cell shows the value, confidence color, and the crop image. User double-clicks low-confidence cells to fix them.
TanStack Table + Virtual GET cells + crops cell_overrides on edit
8

Export CSV

User · Browser → Next.js
User clicks "Export CSV". Next.js merges cells.parsed_value with any cell_overrides.corrected_value (overrides win) and streams a CSV download. Re-running the job preserves user corrections.
GET /api/projects/:id/export.csv cells + cell_overrides

EasyLab — AI Extraction Pipeline

3 stages running on FastAPI · Gemini 2.5 Pro + Flash + PaddleOCR
Input
Once per project
Reference image + user-drawn boxes (normalized 0..1) + field names
Stage A — Template Generation
Gemini 2.5 Pro · once
Input
Reference image (resized to 1568px) + field list with reference_box
Output
semantic_description + expected_format per field, stored in template_fields
for each non-reference image (5 in parallel)
Stage B — Region Detection
Gemini 2.5 Pro · per image
Input
Image (1568px) + all fields with semantic_description
Output
detected_box [ymin,xmin,ymax,xmax] in 0..1000 → normalized 0..1
+ box_confidence per field
↳ found = false → write failed cell, skip Stage C
for each detected field on each image
Stage C — Value Extraction (parallel readers)
Flash + PaddleOCR · per field
Input
Crop from original-resolution image (+8% padding), resized to 768px
Output
raw_text · parsed_value · unit_seen · legible · self_confidence
OCR runs in parallel for reconciliation
reconcile Flash + PaddleOCR
Write Cell Row
Postgres · per cell
combined_confidence = round(0.4 × box + 0.6 × value, 3)
Status: ok (≥0.85) · low_confidence (0.60–0.85) · needs_review (<0.60 or illegible) · failed

Key Rules

JSON schemaEvery Gemini call uses native response_json_schema from Pydantic .model_json_schema(). Validated before downstream use.
EXIF transposeApplied to every image before any stage.
CoordinatesAlways normalized 0..1 against original dimensions. Never display pixels.
Concurrency2 jobs · 5 images per job · 10 max concurrent Gemini calls.
Circuit breaker5 consecutive 5xx → pause job for 60s. 429 → honor retry-after header.
Cost~$0.40 per 50 images × 4 fields. ~50s end-to-end.
